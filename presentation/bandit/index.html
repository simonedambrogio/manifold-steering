Value steering in a bandit

A reproduction and extension of Goodfire (2026) · Manifold Steering Reveals the Shared Geometry of Neural Network Representation and Behavior

The same thesis, in a value-based setting. An agent holds latent value beliefs over the arms of a multi-armed bandit; we ask whether those beliefs live on a structured manifold, and whether steering along it moves the agent's choices the way the geometry predicts.

1 · The task

A four-armed bandit. On each trial the agent chooses an arm and receives a reward, and over time it forms a value estimate for each arm. These values are the quantity we will later read off its internal representation and steer.

2 · Collecting the data

On every trial we hand Llama its own raw history — each past press and its payout — and read the next-token distribution over the arm letters as its choice. We sample that choice, deliver the scheduled reward, append the new line, and repeat. Across roughly 150 trials and 400 episodes this builds the behavioral dataset we model and later steer.

3 · Does it actually learn?

Each grey dot is one episode's relative reward — 0 means choosing at random, 1 means the (impossible) perfect policy. Llama's episodes pile up well above chance: its group average (black) sits at +0.37.

Human participants from the original study (purple, ≈0.6 read from Fig 1f) still do better, but Llama is unmistakably playing the task, not guessing. That above-chance value tracking is exactly what makes the next question — can we steer it? — worth asking.

4 · Which model explains its choices?

We fit a ladder of models to Llama's choices, from a simple Q learner with two parameters (SimpleRL) up to flexible recurrent networks with thousands of parameters (VanillaRNN, MemoryANN).

On action prediction accuracy the six parameter BestRL already matches the much larger RNNs (about 0.49, well above the 0.25 chance line and far above SimpleRL), and the two are statistically indistinguishable (P = 0.98). A compact, interpretable model captures how Llama plays, so we build the rest of the analysis on it.

5 · How Llama plays — the fitted model

A six-parameter Q-learner (delta-rule value + perseveration) fit to Llama's choice distribution recovers the value Qt it tracks and how it turns that value into a choice.

α= 0.16learning rate
f= 0.04forgetting
Qinit= −222value floor
β= 0.016inverse temperature
κp= 1.0persistent stickiness
κt= 1.0transient (repeat last)

Both perseveration terms are pinned at their ceiling and β is tiny: Llama is strongly habitual, inclined to repeat the arm it just chose. Yet a moderate α with slow forgetting means it still tracks reward, while unchosen arms decay toward a deep floor (Qinit ≈ −222). The net strategy: find the best arm, suppress the rest, and stick to it — exploitation driven by a large value gap, not a sharp temperature.

6 · Watching the value move

Run that fitted model forward and you get Qt — Llama's running value for each arm, its internal belief about which option is paying off. Plotted trial by trial (left), it climbs for the arm Llama favours and decays for the rest. Set it beside the schedule's true reward means (right) and the two track. In the bottom episode the best arm even changes hands midway — and Q follows the switch. This trajectory, the value Llama actually carries, is the quantity we set out to steer.

From behavior to geometry

The paper showed that for concepts that are the output (the weekday words), representation geometry shapes behavior. In the bandit the output is a choice, and value is a latent that mediates it but is never emitted.

Does the paper's geometry framework extend to a latent intermediate variable, one the model never outputs?

Our thesis: it does. Value is encoded on a structured manifold, and steering along that manifold moves Llama's choices the way the geometry predicts.

7 · Reading the residual stream

To look inside, we tap the residual stream — the running vector every layer reads from and writes back to as Llama processes the prompt. At the decision token it carries everything the model has computed about the choice it is about to make.

We read it out at a single layer (layer 19), giving one 4096-dimensional activation per trial: a snapshot of Llama's internal state at the moment of choice. Projected onto its top principal components, each trial becomes a point — the raw material for everything that follows: decoding value, mapping its geometry, and steering.

8 · Every arm's value is in there

We train a ridge probe from the layer-19 activation to each arm's value, then test it on held-out episodes. Top row — by arm identity (B, C, D, F): every arm's value lands on a tight line (r² ≈ 0.95). Bottom row — by value rank: the structure is graded — the best arm is read almost perfectly, while the ambiguous 3rd-place value is the fuzziest.

So the residual stream doesn't merely encode which arm is best — it carries the full graded value of all four arms. That is the latent we will map and steer.

9 · The value has a shape

Decoding gives each arm's value; centring across arms (the choice ignores the overall level) and keeping the top directions yields the choice-relevant value subspace. Project every trial into it and the belief takes a clear form: a four-arm simplex. Each corner is a region where one arm (B, C, D, F) is clearly best; the cloud between corners is the graded in-between, and moving along an edge is one arm's value rising as another's falls. This structured surface — the value manifold — is what the rest of the story steers along.

10 · The same shape, unsupervised

The last view built its axes from the decoded value — so a skeptic could call the simplex a self-fulfilling projection. So here we don't. We take the raw layer-19 residual stream and keep only its first three principal components — PCA sees activations alone, no value, no labels.

Within a fixed trial window (so time-in-episode doesn't swamp everything), the same four-arm tetrahedron falls out on its own: trials cluster by which arm is best at 94% (chance 25%), and the fitted value-manifold edges thread right through them. The structure is in the geometry, not in the projection.

11 · Behaviour wears the same simplex

So the representation holds a four-arm simplex. Does the model's behaviour honour it? Embed each trial's choice distribution in the choice simplex: the corners are the four pure-arm choices, and the cloud collapses toward whichever arm is best. The same tetrahedron appears — now in behaviour space. This match between the geometry of the representation and the geometry of behaviour is the structural correspondence at the heart of the thesis.

One twist: the behaviour edges (black) are nearly straight, lying on the linear chords (dashed), while the representation edges curve. The value manifold bends; behaviour doesn't — a non-folding latent. That is exactly why steering it is a question of pacing, not of avoiding wrong-answer detours.

Choice-distribution tetrahedron (barycentric). Black = My edge (Hellinger), dashed = linear mixture; arc/chord ≈ 1.1. Drag to rotate.

12 · Steering the value moves the choice

The causal test. We push Llama's layer-19 activation along the value manifold — the C→D edge — and read its choice from the next-token distribution alone, never touching the output. As the activation slides from the C-is-best corner to the D-is-best corner, the choice hands off in turn: P(C) falls and P(D) rises, tracking the model's natural transition. The geometry doesn't just describe the value — intervening on it moves the behaviour.

And the manifold matters (toggle linear): a straight chord between the same two corners reaches the same endpoints, but at the wrong pace — the manifold matches the natural crossover timing, the line lags. For this non-folding latent the payoff is faithful pacing, not avoiding off-manifold detours.
